[공통 표 계약](../table-contract.md)의 CMP-TABLE-01~08을 상속한다. 숫자 정렬과 기본 정렬은 D-USR-2026-11-16-1·2를 따른다. 그 밖의 검색·필터 추천안은 D-USR-2026-11-16-7의 기본값이다. 열의 값·정렬·톤·툴팁·폭은 아래 열 계약에 적는다. 공통 정렬·빈 값 처리는 CMP-TABLE-01~08을 참조한다.

## CMP-T-GITOPS-DETAIL-01

- 목표: → [RULE-SECRET](../../rules.md#RULE-SECRET). Application의 동일 리비전 적용 결과를 확인한다;  기본 정렬: Application at 내림차순; Helm 이력은 수집·정렬하지 않음; 동점: 원본의 불변 ID 오름차순(리소스는 namespace/kind/name/UID, RBAC는 resource/scope/verbs);  행 이동: 선택 이력의 revision 비교; 원문 파일 링크. 검색·거르기: 선택한 배포 ID와 기간, 표 자체 검색 없음; Helm revision·values를 Secret에서 읽거나 Application의 실패 revision을 성공으로 보이면 실패.
- 현재: Helm 상세는 helmReleases(h.secrets)로 선택 release를 찾는다(`apps/wake/pages/gitops-detail.js:31`).
- 차이: Helm 상세가 Secret 기반 이력·값을 소비한다. 허용 메타 이외 항목을 권한 범위 밖으로 바꿔야 한다.
- 고정 장치: 고정 없음 → TASK-CMP-T-GITOPS-DETAIL
- 출처: D00100 D-01 D00450; D00447; D01051. 그 밖의 검색·필터 기본값은 D-USR-2026-11-16-7.
