# 보고서

<a id="SCR-REPORT"></a> 진입: `wake://cluster/:cluster/incidents/:id/report; wake://cluster/:cluster/report`. 목적(SRE 판단): 영향·원인·대응·후속 조치를 팀에 전달한다.
구성: 문서 머리 → reportCanvas 한 문서 → 스트리밍 조립·정지/재개·선택 삭제·내보내기.
현재: [apps/wake/pages/incident-report.js](../../apps/wake/pages/incident-report.js); [apps/wake/pages/incident-report-doc.js](../../apps/wake/pages/incident-report-doc.js). 정적 코드 확인이며 실제 화면·실클러스터 합격은 미검증이다.
공통: [원본·대상](common.md#SCR-SOURCE-IDENTITY), [7상태](common.md#SCR-STATES), [이동·복귀](common.md#SCR-NAV-RETURN), [검수](common.md#SCR-NATIVE-ACCEPT).
7상태 적용 대상: 사건 보고서, 평상시 점검, 문서 상태·출력; 판정은 → [RULE-STATE](../rules.md#RULE-STATE). 로컬 화면은 설정/호스트 작업 상태에 한정한다.
구성 요소: [CMP-CTRL-SEARCH](../components/controls.md); [CMP-CHART-01](../components/charts.md); [CMP-TABLE-01~08](../components/table-contract.md); [CMP-CARD-01~02](../components/cards.md); [CMP-CHIP-01~03](../components/source-chips.md); [CMP-T-INCIDENT-REPORT-DOC-01](../components/tables/incident-report-doc.md). 표 열과 카드 세부는 components ID를 참조한다.
표별 SRE 판단·기본 정렬/동점·문제 우선·행 이동·검색/거르기와 열 계약: [CMP-T-INCIDENT-REPORT-DOC-01](../components/tables/incident-report-doc.md). 화면의 대상/복귀 계약을 함께 적용한다.

자료: 사건 문서는 incident 서비스의 workspace 스냅숏·evidence·audit, 점검 문서는 checkInput의 summary/nodes/pods/events/alerts를 사용한다. 편집 이후의 정본은 report.state다. 공통 출력 일치는 V03, 문서 유형은 DOCUMENT, 선택 조작은 SELECTION, 인쇄는 PAGINATION을 참조한다.
