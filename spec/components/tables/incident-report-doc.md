# 보고서 표

[공통 표 계약](../table-contract.md)의 CMP-TABLE-01~08을 상속한다. 숫자 정렬과 기본 정렬은 D-USR-2026-11-16-1·2를 따른다. 그 밖의 검색·필터 추천안은 D-USR-2026-11-16-7의 기본값이다. 열의 값·정렬·톤·툴팁·폭은 아래 열 계약에 적는다. 공통 정렬·빈 값 처리는 CMP-TABLE-01~08을 참조한다.

## CMP-T-INCIDENT-REPORT-DOC-01

- 목표: 해결된 incident의 timeline·evidence·verify·followups를 보고서 모델로 만든다 → 선택 근거·검증·후속 작업을 같은 시점의 보고서로 재현한다. 기본 정렬: 문서 섹션 순서; 사건 at 오름차순; 검증/작업은 모델 순서; 동점: 원본의 불변 ID 오름차순(리소스는 namespace/kind/name/UID, RBAC는 resource/scope/verbs). 문제 우선: 보고서 시간 순서를 바꾸지 않고 상태를 표기. 행 이동: 내보내기에서는 근거 링크만; UI 행 동작 제외. 검색·거르기: 보고서 선택 섹션·구간·검색 조건을 모델에 반영. → 발생 시간순 타임라인이 심각도순으로 바뀌거나 미지정 담당자를 만들어 표시하면 실패.
- 현재: 타임라인 rows0는 at 오름차순으로 정렬한 뒤 보고서 행으로 변환한다(`apps/wake/pages/incident-report-doc.js:155`).
- 차이: 같은 at의 타임라인 행에 불변 키 동점 비교가 없다.
- 고정 장치: 고정 없음 → TASK-CMP-T-INCIDENT-REPORT-DOC
- 출처: D00941 D00942 D00944; D00447; D01051. 그 밖의 검색·필터 기본값은 D-USR-2026-11-16-7.
