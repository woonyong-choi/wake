# 리소스 상세 하위 Pod와 HPA

[공통 표 계약](../table-contract.md)의 CMP-TABLE-01~08을 상속한다. 각 열의 현재·차이·고정 장치·출처는 아래 열 계약에 적는다. 정렬은 D-USR-2026-11-16-2, 문제 판단·검색 확장은 D-USR-2026-11-16-7의 기본값을 따른다.

## CMP-T-RESOURCE-INSPECTOR-01

- 목표: 소유 Pod 둘과 HPA current가 없는 target=80% 지표를 넣고 상세를 연다 → 하위 Pod와 HPA 지표의 실제 현재·목표를 대조한다; [RULE-SORT](../../rules.md#RULE-SORT). 문제 우선: 실패·미준비 Pod 우선. 이동: Pod UID 상세; HPA 수치 행 이동 없음. 검색·거르기: 소유 관계·지표 범위, 자체 검색 없음; 누락된 current를 80%나 0으로 채우거나 다른 UID의 Pod를 열면 실패.
- 현재: HPA current와 target은 각각 null 병합으로 빈 셀을 만든다(`apps/wake/pages/resource-inspector.js:78`).
- 차이: HPA 결손 current는 빈 셀이어서 관측 없음 사유가 표시되지 않는다.
- 고정 장치: 고정 없음 → TASK-CMP-T-RESOURCE-INSPECTOR
- 출처: D00450 D00093; D-USR-2026-11-16-2; D00447; D01051. 그 밖의 검색·필터 기본값은 D-USR-2026-11-16-7.
