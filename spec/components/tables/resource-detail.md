# 리소스 상세 안의 표

[공통 표 계약](../table-contract.md)의 CMP-TABLE-01~08을 상속한다. 숫자 정렬과 기본 정렬은 D-USR-2026-11-16-1·2를 따른다. 그 밖의 검색·필터 추천안은 D-USR-2026-11-16-7의 기본값이다. 열의 값·정렬·톤·툴팁·폭은 아래 열 계약에 적는다. 공통 정렬·빈 값 처리는 CMP-TABLE-01~08을 참조한다.

## CMP-T-RESOURCE-DETAIL-01

- 목표: 같은 Pod에 정상 컨테이너와 실패 컨테이너를 넣고 summary의 컨테이너 행을 연다 → 컨테이너·조건·용량·backend·revision 등 종류별 운영 근거를 대조한다. 기본 정렬: 하위 표 정책 표 참조; 동점: 원본의 불변 ID 오름차순(리소스는 namespace/kind/name/UID, RBAC는 resource/scope/verbs). 문제 우선: 현재 상태 표만 문제 우선; 이력은 시간/리비전순. 행 이동: 참조 UID가 있는 리소스만 해당 상세; 속성 행은 이동 없음. 검색·거르기: 상세 대상 UID에 종속; 하위 Pod 이름·상태, 이벤트는 eventTable 계약. → 현재 상태와 마지막 종료가 섞이거나 재시작 숫자 칸에 상태 아이콘이 들어가면 실패.
- 추가 조건: 입력 정상 컨테이너 둘과 긴 이름의 컨테이너 표 → 기대 정상 체크만 이름 바로 오른쪽에 붙이고 별도 우측 정렬 상태 표시 제거 → 실패 체크가 행 오른쪽 끝/별도 열에 떨어져 있거나 정상 상태가 중복 표기.
- 추가 조건: 입력 긴 이름의 정상 컨테이너와 같은 데이터를 가진 요약/독립 탭 → 기대 정상 체크는 이름 옆, 중복 정보는 한곳으로 통합 → 실패 필드가 존재한다는 이유로 상태 위치 오류나 중복 탭을 허용.
- 현재: 컨테이너 표는 containerList에서 label·lastRestartAt·lastExit를 계산한다(`apps/wake/pages/resource-detail.js:521`).
- 차이: 하위 Pod 키는 name이며 namespace·UID 동점 비교가 없다. Secret 키 표 분기도 남아 있다.
- 고정 장치: 고정 없음 → TASK-CMP-T-RESOURCE-DETAIL
- 출처: D00081 D00450 D01033; D00447; D01051. 그 밖의 검색·필터 기본값은 D-USR-2026-11-16-7.; D00369
