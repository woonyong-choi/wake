# Deployment 목록 표

[공통 표 계약](../table-contract.md)의 CMP-TABLE-01~08을 상속한다. 숫자 정렬과 기본 정렬은 D-USR-2026-11-16-1·2를 따른다. 그 밖의 검색·필터 추천안은 D-USR-2026-11-16-7의 기본값이다. 열의 값·정렬·톤·툴팁·폭은 아래 열 계약에 적는다. 공통 정렬·빈 값 처리는 CMP-TABLE-01~08을 참조한다.

## CMP-K-DEPLOYMENTS-01

- 목표: spec.replicas=3, status.availableReplicas=1, updatedReplicas=2인 Deployment를 조회한다 → Desired=3, Available=1, Up-to-date=2를 각각 표시한다(spec.replicas, status). 원하는 복제 수와 가용 수의 차이 및 롤아웃 지연을 판단한다. → [RULE-SORT](../../rules.md#RULE-SORT). 같은 문제 톤과 문제 없는 행 안에서는 namespace → name → UID 오름차순이며 값이 없으면 맨 뒤에 둔다. 문제 기준은 available < desired 또는 실패 조건. 행은 동일 cluster/ns/kind/UID/at의 상세를 연다. 검색은 Name, 필터는 namespace·문제 상태이며 Pod는 Status·Node·Controlled By도 적용한다; 가용 1과 갱신 2를 모두 Ready 3으로 대체하거나 문제 필터에서 제외하면 실패.
- 현재: ROW.deployments가 원본 API 필드를 목록 값으로 변환한다(`apps/wake/data/kinds.js:119`); 목록의 `columns`와 `table`은 `apps/wake/pages/resource-list.js:113,143`에 있다.
- 차이: resources 응답 순서를 필터 후 slice하며 문제 우선·UID 동점 정렬이 없다(`apps/wake/pages/resource-list.js:143–150`).
- 고정 장치: 고정 없음 → TASK-CMP-K-DEPLOYMENTS
- 출처: D00082; D-USR-2026-11-16-2; D00447; D01051. 그 밖의 검색·필터 기본값은 D-USR-2026-11-16-7.
