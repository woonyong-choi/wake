# 그 밖의 부품 입력과 모양 토큰

현재 선언은 값과 입력을 추적하는 근거다. 목표 승인은 선언 존재로 대신하지 않는다. 공통 빈 값·톤·툴팁·7상태·폭·원본 대조는 CMP-TABLE-01~08을 참조한다. 각 행의 TASK ID는 차이의 남은 작업이다. 시험 파일 존재는 현재 실행 통과를 뜻하지 않는다.
