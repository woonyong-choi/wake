## B-TOKEN-001 역할 토큰 계약

- 목표: 입력: 기본·light·desktop·page·reduced-motion 조건으로 같은 버튼·표·메뉴를 렌더링한다 → 기대: 아래 역할 표의 토큰을 사용하고 B-002~005의 승인 값과 역할을 유지한다 → 실패: 같은 역할에 다른 리터럴 색·크기·반경이 쓰이거나 코드 선언을 새 승인값으로 취급하면 실패.
- 추가 조건: 다크·라이트의 실제 보조 글자 배경에서 두 토큰을 각각 표시 → U00600의 선택대로 두 단계 모두 읽기 대비 4.5:1 이상, 구분선 톤 유지 → 어느 단계든 기준 미달하거나 구분선까지 바뀌면 실패.
- 현재: `kit/tokens.css:8`의 :root가 공통 토큰을, `apps/wake/theme.css:97–127`이 본문 밀도와 폭을 덮어쓴다.
- 차이: 본문 pane-max-w의 list-col-w 덮어쓰기가 home·chat 폭을 가린다(`apps/wake/theme.css:110`) → T-B-008.
- 고정 장치: 고정 없음 → T-B-003
- 출처: D00069, D00314, D00812, D00902, D00954, D01018, D01020, D01028.

현재 칸은 해당 역할의 선언·참조·Wake 덮어쓰기까지 적는다. 차이 없음은 그 명시된 CSS 계약의 소스 대조이며 실제 렌더링 합격을 뜻하지 않는다. 현재 선언값은 승인된 역할을 구현하는지 대조할 때 쓴다. 아래 목표는 역할 토큰 참조와 적용 범위이며 선언값 자체를 새 승인 수치로 확정하지 않는다. 모양 변경은 B-001을 따른다.
