# 알약 카드와 요약 막대

현재 선언은 값과 입력을 추적하는 근거다. 목표 승인은 선언 존재로 대신하지 않는다. 공통 빈 값·톤·툴팁·7상태·폭·원본 대조는 CMP-TABLE-01~08을 참조한다. 각 행의 TASK ID는 차이의 남은 작업이다. 시험 파일 존재는 현재 실행 통과를 뜻하지 않는다.

## CMP-CARD-01 — 머리·본문·펼침

- 목표: body가 있는 summaryBar를 닫고 같은 items 값으로 재조회한다 → summaryBar는 label/items/body/open/toggle을 받는다. 본문이 있을 때만 꺾쇠와 펼침을 만들며 본문 없는 행은 동작을 암시하지 않는다. 자동 펼침 판단은 [RULE-FOLD](../rules.md#RULE-FOLD)를 따른다. 사람의 펼침·접힘 상태는 갱신·테마 변경·추가 자료에서도 보존한다. C안은 빈자리를 먼저 그리고 데이터 도착 때 이미 열린 틀의 내용만 채운다. 종류 이름만 반복하는 머리 대신 상태·문제 수·최근 변화·기간의 판단값을 둔다. → p.open과 사용자 접힘 기록이 다르게 표시되거나 본문 없는 행에 꺾쇠가 생기면 실패.
- 추가 조건: 같은 작업을 접힘/펼침으로 전환 → 요약은 기존 점 크기의 원형 상태 장치와 같은 상태 모션·주기 사용 → 접힌 쪽이 정적이거나 크기/상태/모션이 달라지면 실패. 공통 판정은 [B-044](../design.md#B-044)에 연결한다.
- 추가 조건: 긴 이벤트 요약을 좁은 폭에서 표시 → 요약 머리는 승인된 한 줄/우선순위 생략 방식, 카드 사이는 승인된 간격만 유지 → 요약이 두 줄이 되거나 별도 중간 선이 추가되면 실패.
- 현재: summaryBar.render는 body가 있을 때 details와 꺾쇠를 만들고 매 렌더의 p.open을 반영한다(`kit/components/summary-bar.js:96–102`).
- 차이: 부품은 최초 자동 펼침 여부를 저장하지 않는다. 호출 화면의 folded/초기 값 관리가 필요하다.
- 고정 장치: `kit/components/summary-bar.test.mjs` — `the open state is the caller's on every drawing: a closed bar is drawn closed again, and drawing the same thing twice gives the same markup (nothing to replay)`; 추가 조건 고정 없음
- 출처: D00700, D00919, D00952, D00955, D01021, D01027; D00694; D00876

## CMP-CARD-02 — 모양·꺾쇠·밀도

- 목표: 우선순위가 다른 items 8개를 좁은 카드에 넣고 머리와 꺾쇠를 각각 가리킨다 → 본문에 카드 안 카드를 겹치지 않는다. 머리 items는 우선순위로 접고 생략된 항목은 더보기에서 전체 접근 가능해야 한다. 머리 전체 hover는 글색만, 꺾쇠 자체 hover/focus에서만 배경을 준다. 창 밖으로 포인터가 나가면 남은 hover를 지운다. 요약은 상태 막대 → 시간 → 지표 → 상태·컨테이너 표 → 조건 → 종류별 속성 → 라벨 순서이며 별도 사양 카드는 요약에 합친다. → 더보기에서 항목을 잃거나 머리 전체에 바탕이 생기거나 중첩 카드가 나타나면 실패.
- 현재: summary:hover가 꺾쇠 바탕을 켜고 keepOf는 priority가 낮은 items부터 접는다(`kit/components/summary-bar.js:57,123–132`).
- 차이: 머리 전체 hover로 꺾쇠 바탕이 켜진다. 목표는 꺾쇠 자체 hover/focus에서만 바탕이다.
- 고정 장치: `kit/components/summary-bar.test.mjs` — `fold keeps every item while the least widths fit, and otherwise as many leading items as fit beside the mark`
- 출처: D00637, D00678, D01007, D01040
