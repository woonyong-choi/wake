# 홈 문제 Pod·워크로드·이벤트

[공통 표 계약](../table-contract.md)의 CMP-TABLE-01~08을 상속한다. 숫자 정렬과 기본 정렬은 D-USR-2026-11-16-1·2를 따른다. 그 밖의 검색·필터 추천안은 D-USR-2026-11-16-7의 기본값이다. 열의 값·정렬·톤·툴팁·폭은 아래 열 계약에 적는다. 공통 정렬·빈 값 처리는 CMP-TABLE-01~08을 참조한다.

## CMP-T-CLUSTER-HOME-01

- 목표: resources에 CrashLoopBackOff Pod와 Ready Pod, events에 같은 대상의 반복 Warning을 넣고 홈을 연다 → 문제 Pod·워크로드·최근 경고 이벤트에서 조사 대상을 고른다; [RULE-SORT](../../rules.md#RULE-SORT). 문제 우선: 리소스만 위험·주의 우선, 이벤트는 시간순. 행 이동: 동일 cluster/ns/kind/UID의 상세 또는 해당 이벤트. 검색·거르기: 클러스터 전체 이름 검색; 원래 카드의 문제 집합 필터 유지; 정상 Pod가 문제 목록에 섞이거나 같은 Event 반복을 별개 장애로 중복 집계하면 실패.
- 현재: 문제 Pod는 bad.slice(0,8)이며 행 키는 namespace/name이다(`apps/wake/pages/cluster-home.js:270`).
- 차이: Pod 키에 UID가 없어 같은 이름으로 재생성된 Pod의 선택을 구분하지 못한다.
- 고정 장치: 고정 없음 → TASK-CMP-T-CLUSTER-HOME
- 출처: D00081 D00090 D00093; D-USR-2026-11-16-2; D00447; D01051. 그 밖의 검색·필터 기본값은 D-USR-2026-11-16-7.
