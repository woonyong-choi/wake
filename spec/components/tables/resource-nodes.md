# Node 목록 표

[공통 표 계약](../table-contract.md)의 CMP-TABLE-01~08을 상속한다. 각 열의 현재·차이·고정 장치·출처는 아래 열 계약에 적는다. 정렬은 D-USR-2026-11-16-2, 문제 판단·검색 확장은 D-USR-2026-11-16-7의 기본값을 따른다.

## CMP-K-NODES-01

- 목표: Ready=False, MemoryPressure=True인 Node를 조회한다 → Status는 NotReady 오류, Pressure는 MemoryPressure로 보인다(status.conditions). NotReady·압박·스케줄 제외와 용량 대비 사용을 구분한다. → [RULE-SORT](../../rules.md#RULE-SORT). 같은 문제 톤과 문제 없는 행 안에서는 namespace → name → UID 오름차순이며 값이 없으면 맨 뒤에 둔다. 문제 우선: Ready=False/Unknown 또는 MemoryPressure/DiskPressure/PIDPressure=True. 검색 Name; 필터 namespace·문제 상태; Pod만 Status·Node·Controlled By 추가. 동일 cluster/ns/kind/UID/at 상세로 이동한다; Ready가 정상으로 보이거나 MemoryPressure가 표·상세에서 사라지면 실패.
- 현재: ROW.nodes가 원본 API 필드를 목록 값으로 변환한다(`apps/wake/data/kinds.js:171`); 목록의 `columns`와 `table`은 `apps/wake/pages/resource-list.js:113,143`에 있다.
- 차이: resources 응답 순서를 필터 후 slice하며 문제 우선·UID 동점 정렬이 없다(`apps/wake/pages/resource-list.js:143–150`).
- 고정 장치: 고정 없음 → TASK-CMP-K-NODES
- 출처: D00085; D-USR-2026-11-16-2; D00447; D01051. 그 밖의 검색·필터 기본값은 D-USR-2026-11-16-7.
